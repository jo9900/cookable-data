## 1. 关于本政策

烧了吧（以下简称"本应用"）由独立开发者维护。我们尊重并保护你的隐私。本政策说明本应用如何处理你的信息，请仔细阅读。如有任何疑问，请通过文末联系方式与我们联系。

## 2. 我们收集的信息

**简而言之：我们不收集你的任何个人信息。**

本应用 v0.1 完全本地运行，不需要注册、登录、手机号或其他任何账户信息。

具体而言：

- **不收集**身份信息（姓名、电话、邮箱、身份证号等）
- **不收集**位置信息
- **不收集**联系人、相册、通讯录等设备权限
- **不收集**设备识别符（IDFA / UUID）
- **不收集**使用行为数据 / 埋点 / 分析数据
- **没有**广告 SDK 或第三方追踪

## 3. 信息存储位置

你在本应用中产生的所有数据，包括：

- 装备库（已勾选的烹饪手法 / 食材 / 调味料 / 香料）
- 黑名单
- 隐藏的菜
- 收藏的菜
- 偏好设置

**全部仅保存在你设备本地**（iOS 应用沙盒），不会上传到任何服务器。

## 4. 网络请求说明

本应用会从公开 GitHub 仓库 `https://github.com/jo9900/cookable-data` 拉取菜谱 JSON 数据，用于在不发版的情况下更新菜单。

- 此请求**不携带**任何用户身份信息（无 Cookie、无 Token、无自定义 UA）
- GitHub 的访问日志由 GitHub 公司维护，请参考 [GitHub 隐私政策](https://docs.github.com/site-policy/privacy-policies)
- 请求失败时，本应用会回落到内置菜谱，离线可用

## 5. 信息共享

由于我们不收集任何信息，因此**不存在**信息共享、转让、对外披露的情形。

## 6. 信息安全

由于所有数据存于本机沙盒：

- 你卸载本应用时，所有数据自动清除
- 在"设置 → 收藏 / 黑名单 / 隐藏菜"中均提供清空 / 移除按钮
- iOS 系统沙盒机制天然隔离其他应用对本应用数据的访问

## 7. 未成年人

本应用不针对 14 岁以下儿童。鉴于本应用不收集任何信息，也不存在面向未成年人的特殊处理需求。如果你是未成年人的监护人并发现本应用有任何不当内容，请通过下方联系方式与我们沟通。

## 8. 第三方服务

本应用 v0.1 涉及的第三方仅有：

| 服务方 | 用途 | 数据交换 |
|---|---|---|
| GitHub (raw.githubusercontent.com) | 拉取菜谱 JSON | 无用户身份信息 |
| Apple App Store | 应用分发与更新 | 由 Apple 处理 |

未来版本如新增第三方服务（如 UGC 上传后端、第三方视频跳转、付费分析），本政策将相应更新并在生效前通过应用内提示告知。

## 9. 本政策的更新

本应用更新版本时，如涉及数据处理方式变化，将通过 App Store 更新说明、应用内提示等方式告知。
